Kurulum bir kez, bu cihazda

Panel gizli vumeloo-agent ve namistain-ops repolarını senin salt-okunur anahtarınla okur. Anahtar sadece bu tarayıcıda saklanır, hiçbir yere gönderilmez (yalnızca GitHub'a).

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Ad: jarvis-panel, süre: 1 yıl.
  3. Repository access: Only select repositories → vumeloo-agent ve namistain-ops.
  4. Permissions → Repository: Actions: Read-only ve Contents: Read-only. Başka hiçbir şey açma.
  5. Oluşan anahtarı aşağıya yapıştır.
